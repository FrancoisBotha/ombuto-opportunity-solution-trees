Style guide

How the opportunity solution tree is drawn. Every value here comes from the Nocturne tokens — a dark blue-grey ground, Inter at 400/500, 8px radii, and one blurple accent used as line and glow rather than fill. The only deliberate exception is the priority spectrum, which is a cold-to-warm scale in its own right.

03 — Node taxonomy

Type is carried by frame, never by hue: a filled accent-900 plate for the spine (product, outcome), an accent outline for opportunities, a neutral plate for solutions, a dashed outline for assumptions, and a quiet hairline italic for evidence. All nodes are 8px radius, 9/11px padding, with a kicker, a 15px title and a meta row.

Overview

Edges are orthogonal three-segment paths from parent bottom-centre to child top-centre: 1.6px accent-600 for the spine, 1.1px dashed for assumptions and evidence. Selection is a 2px solid accent outline at 2px offset; a legal drop target is a dashed accent outline at 3–4px offset with an accent-800 wash. The dot grid is the text colour at 9%, 28px pitch.

07 — Motion & interaction
Layout
Nodes ease to new positions over 180 ms (left/top). A node being dragged drops the transition entirely and takes --shadow-lg.
Zoom
Cursor-anchored wheel zoom, 1.08× per notch, clamped 0.35–1.6. Fit never goes below 0.68 — legibility outranks seeing everything.
Hover & focus
Hover tints come from accent-900/800; focus is Nocturne's 2px accent :focus-visible ring. No default browser states anywhere.
Dismissal
Overlays close on backdrop click and Escape. Closing the detail panel hides it but keeps the selection, so reopening is one click.
08 — Rules
Do
  • Distinguish node types by frame and fill weight, not by hue.
  • Keep one meta row per node — status, then one metric, then the thread count.
  • Let derived numbers look derived: read-only bars, never editable inputs.
  • Put every value on the ramps; reach for 700–900 to fill and 100–300 to write on it.
  • Give collapsed structure a count so nothing hides silently.
Don't
  • Flood an area with the accent — it is a line and a glow, not a field.
  • Add a red/amber/green status set; the three badge voices already carry it.
  • Stack more than two numbers on a node; the panel is where detail belongs.
  • Introduce a second typeface or push headings past weight 500 (600 on node titles is the ceiling).
  • Let a control appear for a type that shouldn't have it — confidence is for assumptions, priority and value for opportunities.
